# Classic visualization

Preserved original visualization from commit `f42ea2811fb967c172d78175c62eedab55259e17`.
Its components, scene, theme, and feed logic are independent of the active
workstation so the original appearance and behavior remain available.

Open `/?ui=classic` to use this version; `/` opens the active workstation.
The root HTML shell and dependencies are shared. Styles for the workstation
are loaded only when that version is selected.
